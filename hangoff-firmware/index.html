HangOff

本体のアップデート

パソコンでファイルを1つコピーするだけ。専用のソフトはいりません。
5分くらいで終わります。

用意するもの

  • 1パソコン（Windows か Mac）
  • 2USB-C ケーブル（データ通信ができるもの。充電専用のケーブルでは できません）
  • 3HangOff 本体（XIAO の基板）

スマホやタブレットでは書き込めません。パソコンで行ってください。

いちばん新しいプログラム

読み込み中…
ダウンロード

押すと HangOff-v○○.uf2 というファイルが「ダウンロード」フォルダに保存されます。

手順

  1. ファイルをダウンロードする

    上の「ダウンロード」ボタンを押します。

    ファイルは「ダウンロード」フォルダに入ります。名前は HangOff-v○○.uf2 です（○○ は版の番号）。

  2. ファイルに鍵のマークがないか見る（Windows）

    「ダウンロード」フォルダを開いて、ダウンロードしたファイルのアイコンを見ます。

    鍵のマークがなければ、何もしなくて大丈夫です。次の手順へ進んでください。Mac の人も、この手順はとばしてください。

    鍵のマークがあれば、ファイルが暗号化されています。このままでは書き込めないので、次のようにして暗号化を外します。

    1. ファイルを右クリックして、「プロパティ」を選ぶ
    2. 「全般」タブの「詳細設定」を押す
    3. 「内容を暗号化してデータをセキュリティで保護する」のチェックを外す
    4. 「OK」を押し、もう一度「OK」を押す

    確かめ方: 鍵のマークが消えれば、暗号化が外れています。

  3. 本体の電源を切る

    受信機やサーボ用のバッテリーを外して、本体に電気が来ていない状態にします。

    大事: バッテリーをつないだまま USB をつなぐと、サーボが急に動くことがあります。

  4. 本体をパソコンに USB でつなぐ

    本体（XIAO）の USB-C と、パソコンをケーブルでつなぎます。

  5. リセットボタンを「トントン」と素早く2回押す

    USB の差し込み口のすぐ横に、とても小さなボタン（RST）があります。これを素早く2回押します。

    うまくいくと、パソコンに XIAO-SENSE という名前の USBメモリのようなもの が現れます。

    • Windows: エクスプローラーの「PC」の中や、画面の右下に出ます。
    • Mac: デスクトップや Finder の左側に出ます。

    コツ: ボタンはとても小さいので、爪の先で押すと押しやすいです。「トン…トン」とゆっくりだと、ふつうの再起動になってしまいます。「トントン」と素早く押してください。

  6. ファイルを XIAO-SENSE にドラッグする

    ダウンロードした .uf2 のファイルを、XIAO-SENSE の中へドラッグ＆ドロップします（コピーでも大丈夫です）。

    数秒で書き込みが終わり、XIAO-SENSE は自動で消えます。本体が新しいプログラムで動き始めます。

    安心してください: 「ディスクが正しく取り出されませんでした」などのメッセージが出ることがありますが、正常です。閉じてかまいません。

  7. 新しい版になったか確かめる

    USB を抜いて、いつものようにバッテリーをつなぎます。

    スマホで HangOff 設定 を開いて本体に接続します。タイトルの横の「本体 v○○」が、上の「いちばん新しいプログラム」と同じなら完了です。

    設定や基準姿勢、記録したデータは、アップデートしても消えません。

困ったとき

XIAO-SENSE が出てこない
  • ボタンを押す速さを変えて、何回か試してください。「トントン」と素早く押すのがコツです。
  • ケーブルを別のものに変えてください。充電専用のケーブルでは出てきません。
  • パソコンの別の USB の差し込み口につないでみてください。USB ハブを使っているときは、パソコンに直接つないでください。
名前が XIAO-SENSE ではない

ボタンを2回押したときに新しく出てきたもので、中に INFO_UF2.TXT というファイルがあれば、それで合っています。そこへファイルをドラッグしてください。

ドラッグしたのに XIAO-SENSE が消えない／版が変わらない
  • ドラッグしたファイルの名前が .uf2 で終わっているか確かめてください。
  • もう一度、手順5（ボタンを2回押す）からやり直してください。
コピーしても XIAO-SENSE が消えない（Windows）

ダウンロードしたファイルが暗号化されていると、コピーしたように見えても書き込まれません。手順2を見て、ファイルの鍵のマークを外してから、手順5からやり直してください。

失敗したら本体が壊れない？

壊れません。書き込みの途中でケーブルが抜けても、ボタンを2回押せば何度でもやり直せます。

設定は消えない？

消えません。角度の設定、基準姿勢、記録したデータは、そのまま残ります。
